# Coffesy - Modern Coffee Shop Web Application

A full-stack web application built to manage a coffee shop catalog and user authentication. This project implements a clean client-server architecture with secure session management using Google OAuth.

**Developed by:** Muhammad Chairul Hamsy

## 🛠 Tech Stack

| Category | Technology |
| :--- | :--- |
| **Frontend** | Next.js, React, Tailwind CSS |
| **Backend** | Node.js, Express.js (v5) |
| **Database** | PostgreSQL, Prisma ORM |
| **Authentication**| Better Auth (Google OAuth) |
| **Package Manager**| pnpm |

## 🚀 Getting Started

### Prerequisites
Ensure you have the following installed on your local machine:
* Node.js (v18 or higher)
* PostgreSQL
* pnpm (`npm install -g pnpm`)

### 1. Installation
Clone the repository and install dependencies for both frontend and backend using a single command (if utilizing a monorepo structure):
